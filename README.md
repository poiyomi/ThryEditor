# ThryEditor

The most advanced Shader Inspector/Editor for Unity with a focus on VRChat.

This is a dedicated fork of ThryEditor containing many more features and improvements built on top of the original code, specifically designed for Poiyomi Shaders.

All the code retained in this repository appears in Poiyomi Shaders v10.0 and newer. As such, please ensure you use the latest version of Poiyomi Shaders in order to use these scripts.

> [!WARNING]
> If you have been referred to this page, please follow the instructions below...
>
> To update ThryEditor:
> 1. Click on `Code` from above, and click `Download as ZIP`.
> 2. Extract the .ZIP contents and place the contained `ThryEditor` folder into the `_PoiyomiShaders -> Scripts` folder, replacing the existing one.
> 3. Let Unity compile.
>
> *This method may not work with VCC versions, as VCC will overwrite this folder on project launch.*
>
> Requires Unity 2022.3 or newer.

More detailed information of the code here in the Poiyomi Docs: https://www.poiyomi.com/thryeditor/
