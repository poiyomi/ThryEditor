Property Options

None of the poperty options are required.
Options are defined in the display name of a property inside curly brackets and after "--":
In practice:
_Tex("Texture--{Put all your options in here}",2D) = "white" { }
_Tex("Texture--{offet:2,hover:read this on hover,altClick{type:URL,data:http://thryrallo.de}}",2D) = "white" { }
Use json syntax instead to future proof your properties!
You can use '' instead of " inside property display names
Example:
{''text'':''Youtube'',''action'':{''type'':''URL'',''data'':''https://www.youtube.com/''}

Condition

A condition is an expression string, for example _ForceOpaque==1 or (_Mode==1 || _Mode==2) && _EnableAudioLink==1.

Comparisons
<value><Comparator><value> with the comparators ==, !=, >, <, >=, <=. A value can be:
value meaning example
number a constant _LightingType==2
<PropertyName> the value of a material property _Cutoff>0.5
RenderQueue the render queue of the material RenderQueue>=3000
A property name on its own always counts as true, so write _ForceOpaque==1, not _ForceOpaque.

Other terms
term meaning
true, false constants
isAnimated(<PropertyName>) true if the property is marked as animated
isNotAnimated(<PropertyName>) true if the property is not marked as animated

Combining
Combine terms with && (and) and || (or). Both have the same priority, so use parentheses when mixing them, for example (_A==1 && _B==1) || _C==1. Put ! in front of a term or a bracket to invert it, for example !(_A==1 && _B==1).
